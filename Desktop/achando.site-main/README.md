# achando.site

Landing page estática do projeto achando.site.

## Tecnologias

- HTML
- CSS
- JavaScript
- `serve` para rodar localmente

## Como rodar localmente

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o servidor local:
   ```bash
   npm start
   ```
3. Acesse no navegador:
   ```text
   http://localhost:3000
   ```

## Estrutura principal

- `index.html` — página principal
- `privacidade.html` — política de privacidade
- `termos.html` — termos de uso
- `robots.txt` — regras de indexação
- `sitemap.xml` — mapa do site
- `assets/` — recursos visuais e fontes
- `hero/` — arte do hero section

## Observações

Este projeto é um site estático, então não há build pipeline complexo. O objetivo principal é servir os arquivos HTML diretamente em produção ou em um ambiente local.
